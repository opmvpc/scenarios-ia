## Problèmes → solutions
- **Heredoc Python avec accents sous Git Bash** : les caractères non ASCII du motif arrivent
  abîmés, et `str.count` renvoie 0. Écrire le script dans un fichier .py (outil Write), puis
  l'exécuter.
- **Analyses ponctuelles avec le moteur** (équilibrage, inventaire) : vitest n'inclut que
  `tests/**`. Écrire un `tests/tmp-*.test.ts` qui écrit son résultat dans un fichier, ou qui
  le fait échouer avec `expect(...).toBe('')`, puis le supprimer.
- **Insérer une clé dans un YAML sans le reformater** : `parseDocument` (paquet `yaml`)
  donne le `range[0]` de chaque bloc ; on insère `image: …` à cette position, en partant de
  la fin du fichier.
- **Prénoms des auteurs** : Thomas Braibant et Sylvain Corrillon. Toujours les reprendre de
  `app/pages/credits.vue`, jamais de mémoire.
- **Disque plein** : les téléchargements échouent en laissant des .jpg de 0 octet, que
  fetch.py prend ensuite pour déjà téléchargés. Les supprimer (`find -size 0 -type f`)
  avant de reprendre.
- **Docker ne rend pas l'espace après un `prune`** : `docker_data.vhdx` n'est pas sparse.
  `fstrim` ne suffit pas ; il faut quitter Docker Desktop, faire `wsl --shutdown`, puis
  `diskpart` en administrateur (`compact vdisk`). L'agent n'a pas le droit de passer en
  administrateur : donner la commande à Thibault.
