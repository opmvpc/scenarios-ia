## Problèmes → solutions (suite)
- **Tailwind v4 annule le `margin: auto` des `<dialog>`** : ils s'ouvrent en haut à gauche.
  Remettre `dialog { margin: auto }` dans la couche base ; `::backdrop` en couleur en dur
  (il n'hérite pas toujours des variables CSS).
- **Clic pendant une transition `out-in`** : l'écran sortant reste cliquable ~200 ms ; un
  « Décider » cliqué là écrasait la décision. `decider()` refuse désormais d'écraser un
  choix existant (il faut passer par `changerDecision`).
- **Reprise après rechargement** : le pas de l'URL doit primer sur le pas sauvegardé
  (borné par `pasMax`), sinon un F5 renvoie ailleurs.
- **Navigateur intégré** : l'émulation de taille saute dès que le panneau change ; refaire
  `resize_window` juste avant chaque capture ; « did not finish rendering » = réessayer.
  Pour le contenu, `get_page_text` / JS sont plus fiables que les captures.
- `preview_start` cherche `.claude/launch.json` dans le dossier de session (cours-ifosup),
  pas dans le repo : lancer `npx nuxi dev` en arrière-plan avec Bash et `navigate`.
- Heredoc + Python sous Git Bash : `'\'` et `⁠` sont mangés ; passer par un fichier
  .py ou par `os.path.basename`.

## Problèmes → solutions (v2)
- **Deux instances de `usePartie` dans un test** : leurs observateurs de route se renvoyaient
  la balle (récursion infinie). Envelopper chaque instance dans `effectScope()` et l'arrêter
  en `afterEach`.
- **Historique après « changer d'avis »** : le bouton avant ramenait l'ancien parcours.
  Une trace `r=` dans l'URL, renouvelée à chaque nouveau parcours ; l'observateur ignore les
  entrées d'une autre trace et borne `?pas=` à `pasMax`.
- **Clic venu d'un écran qui s'efface** : `suivant(depuis)` ; chaque écran capture son pas
  au montage (`const ici = partie.pas.value`).
- **Sauvegarde invalidée par une coquille** : version = hash de la seule structure
  (ids, effets, conditions, fins).
- **Tests par script dans le navigateur intégré** : les transitions ne progressent pas tant
  que le panneau ne se redessine pas ; injecter
  `.ecran-enter-active,.ecran-leave-active{transition:none!important}`. Le clic via
  `computer` échoue parfois (« not on screen ») : cliquer via `javascript_tool`.
- **Le HMR réinitialise l'état des composants** : recharger la page avant de conclure qu'un
  changement n'est pas pris.
- **Un code de partie « faux positif »** : S1-3-C-C-A est vraiment invalide (après
  « location », C = fin anticipée). Vérifier la structure avant de soupçonner le décodeur.
